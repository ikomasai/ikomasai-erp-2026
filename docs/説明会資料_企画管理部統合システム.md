## スライド 2｜このシステムでできること（全体像）

当日の「伝達・対応・記録」をアプリに集約し、対応漏れと属人化をなくします。

| ロール | 使う画面 | 主なこと |
|---|---|---|
| 出展団体 | 企画者サポート | 質問・緊急連絡・開始終了報告・鍵申請 |
| 巡回担当 | 巡回サポート | タスク受諾・現地確認・巡回チェック |
| 本部 | 本部サポート | 全体監視・返信・割当・鍵管理 |
| 会計部 | 会計対応 | 配布基準変更の確認・返信 |
| 物品部 | 物品対応 | 物品破損報告の確認・返信 |

**2本柱:** 「連絡案件」で情報を受け取り、「巡回タスク」で現地対応を動かす。

---

## スライド 3｜全体の連携フロー

```
出展団体（企画者サポート）
  │
  ├─ 質問・相談 ──────────────→ 本部 / 会計 / 物品 が返信
  ├─ 緊急連絡 ────────────────→ 本部 が即時確認・巡回へ割当
  ├─ 開始 / 終了報告 ──────────→ 巡回サポートにタスクが自動生成
  └─ 鍵の事前申請 ─────────────→ 本部 が承認・貸出

本部サポート
  │
  ├─ 全案件を監視・返信・ステータス更新
  ├─ 巡回タスクを割当・進捗確認
  └─ 鍵返却 → 施錠確認タスクを巡回へ自動生成

巡回サポート
  │
  ├─「向かいます」→ 現地確認 →「完了登録」
  └─ 結果が本部・企画者にフィードバック
```

## スライド 4｜企画者サポート（出展団体向け）

### 画面の場所
サイドメニュー → **企画者サポート**

### 4つのタブ

| タブ | できること |
|---|---|
| 質問 | ルール変更・配置図変更・配布基準変更・物品破損を相談 |
| 緊急 | 緊急呼び出し（現在地を入力して送信） |
| 鍵申請 | 鍵の事前借用を申請（借受人・団体・鍵を選択） |
| 開始終了 | 企画開始 / 企画終了を報告 |

---

## スライド 5｜企画者サポート｜質問タブの使い方

1. **質問種別を選ぶ**（4択ボタン）
   - 企画ルール変更 → 本部へ
   - 配置図変更 → 本部へ
   - 商品配布基準変更 → 会計へ
   - 物品破損報告 → 物品へ

2. **相談内容を入力する**（テキストエリア）

3. **送信する**

> 写真が必要な相談は Discord で連絡してください（質問タブでは写真添付不可）

送信後は同じタブの下に「最新連絡案件」として履歴が表示されます。
本部 / 会計 / 物品からの返信もここで確認できます。

---

## スライド 6｜企画者サポート｜緊急タブの使い方

1. **現在地・場所を入力する**（必須）
   - 例: A館2F廊下、正門前
2. **緊急内容を入力する**（任意）
3. **送信する**

> 送信すると「企画管理部に連絡案件を送信しました」と表示されます。

本部が即時通知を受け取り、必要に応じて巡回担当を割り当てます。

---

## スライド 7｜企画者サポート｜鍵申請タブの使い方

1. **借受人を選択する**（名前で検索）
2. **団体を選択する**（団体名で検索）
3. **棟を選ぶ**（ドロップダウン）
4. **鍵を選んで「この鍵を追加」**（貸出中の鍵は選択不可）
5. **送信する**

> 申請後、本部が承認すると貸出記録が自動作成されます。

---

## スライド 8｜企画者サポート｜開始終了タブの使い方

1. **「開始報告」または「終了報告」を選ぶ**
2. **送信する**

> 送信すると巡回担当へ「確認タスク」が自動生成されます。
> 巡回担当が現地確認して結果を本部に返します。

---

## スライド 9｜巡回サポート（巡回担当向け）

### 画面の場所
サイドメニュー → **巡回サポート**

### 4つのタブ

| タブ | できること |
|---|---|
| タスク | タスク一覧の確認・「向かいます」→「完了」操作 |
| チェック | 定常巡回の記録 + 未巡回アラートの確認 |
| 評価 | 企画評価タスクの現地評価入力 |
| ダッシュ | 今日の対応件数サマリー |

---

## スライド 10｜巡回サポート｜タスクの種類

| アイコン | 種別 | 発生元 |
|---|---|---|
| 🚨 | 緊急対応 | 本部が発行 |
| ▶️ | 企画開始確認 | 企画開始報告から自動生成 |
| ⏹️ | 企画終了確認 | 企画終了報告から自動生成 |
| 🔒 | 施錠確認 | 鍵返却時に自動生成 |
| 🚶 | 定常巡回 | 本部が発行 |
| 📋 | その他 | 本部が発行 |

タスクは**種別ごとにグループ化**されて表示されます。
検索欄で企画名・場所・種別を絞り込めます。

---

## スライド 11｜巡回サポート｜タスク対応の手順

1. **タスクタブ** でタスクを選ぶ
   → 自動で「タスク詳細」へスクロール

2. **「向かいます」ボタン**を押す
   → ステータスが「受諾」に変わる

3. 現地で確認する

4. **結果を選んで「完了登録」**

| タスク種別 | 選べる結果 |
|---|---|
| 開始確認 | 問題なし / 開始していない / 別対応必要 |
| 終了確認 | 問題なし / 終了していない / 別対応必要 |
| 施錠確認 | 施錠済 / 未施錠 / 確認不可 |
| 緊急・その他 | 問題なし / 別対応必要 |

> ⚠️「向かいます」を押す前に「完了登録」はできません。

---

## スライド 12｜巡回サポート｜チェックタブの使い方

定常巡回の記録を残します。

**記録する内容（5項目）:**
- 企画書通り進行中か
- 体調不良はいるか
- 困りごとはあるか
- 迷惑来場者はいるか
- 無人・未施錠教室はあるか

各項目で選択肢を選ぶだけで記録完了。

下部の **未巡回アラート** では、一定時間巡回していない場所を確認できます（閾値は本部が設定）。

---

## スライド 13｜巡回サポート｜評価タブの使い方

本部が生成した「企画評価タスク」をここで処理します。

1. 評価タスクを選ぶ
2. 「向かいます」を押す
3. 現地で各評価項目に **点数（0〜5点）とコメント** を入力
4. 総評メモを入力（任意）
5. 「完了登録」

**評価項目（例）:**
- 企画書通りの進行
- 安全管理
- 来場者対応
- 設営・片付け
- 全体印象

## スライド 14｜本部サポート（本部担当向け）

### 画面の場所
サイドメニュー → **本部サポート**（管理者のみ閲覧可能）

### タブ一覧

| タブ | 機能 |
|---|---|
| ダッシュボード | 全体状況の俯瞰 |
| 連絡案件 | 全案件の確認・返信・ステータス更新 |
| 鍵管理 | 貸出 / 返却 / 予約承認 / 施錠確認依頼 |
| 巡回 | タスク一覧・担当割当・削除 |
| 独自タスク | 本部発行の独自巡回タスク作成 |
| 無線 | 無線ログの記録・閲覧 |
| 鍵マスタ | 鍵マスタ管理 |
| 設定 | 未巡回アラート閾値・評価項目の設定 |
| 実績 | 担当者別タスク実績集計（パスワード認証あり） |

---

## スライド 15｜本部サポート｜連絡案件タブの使い方

1. **案件一覧から案件を選ぶ**
   → 自動で詳細へスクロール

2. **内容を確認する**

3. **ステータスを変更する**（ボタン式）
   - 未対応 → 対応中 → 完了

4. **返信を入力して送信する**

5. 必要なら **「部員が向かいます」ボタン** で巡回タスクを生成・割当

> 対応した会計・物品からの返信もここで全て確認できます。

---

## スライド 16｜本部サポート｜鍵管理タブの使い方

**貸出の流れ:**
1. 借受人・団体・鍵を選択
2. 「貸出」ボタンを押す

**返却の流れ:**
1. 貸出中一覧から返却する鍵を選ぶ
2. 「返却」ボタンを押す
3. → 施錠確認タスクが巡回へ自動生成される

**予約承認:**
- 企画者から来た鍵の事前申請を一覧で確認
- 「承認」を押すと貸出記録が自動作成される

---

## スライド 17｜本部サポート｜巡回タブの使い方

1. **タスク一覧でタスクを選ぶ**
   → 自動で「担当者選択」へスクロール

2. **担当者を選ぶ**（企画管理部メンバーのみ候補に出る）
   - すでに対応中タスクを持つメンバーは選択不可

3. **「割り当てて更新」ボタン**を押す

4. **不要なタスクは削除可能**（確認ダイアログあり）

---

## スライド 18｜会計対応（会計部向け）

### 画面の場所
サイドメニュー → **会計対応**（会計部のみ閲覧可能）

### 2つのタブ

| タブ | 内容 |
|---|---|
| 連絡案件 | 「商品配布基準変更」の連絡を受けて対応する |
| 景品配布基準 | 配布基準の内容を確認・編集する |

---

## スライド 19｜会計対応｜連絡案件タブの使い方

対象案件: **商品配布基準変更（出展団体から）のみ**

1. 案件一覧から案件を選ぶ
2. 内容を確認する
3. **ステータスをボタンで変更する**
   - 未対応 → 対応中 → 完了
4. **返信を入力して送信する**（確認ダイアログなし・即送信）

> 送信後、出展団体の「企画者サポート」画面に返信が届きます。

---

## スライド 20｜物品対応（物品部向け）

### 画面の場所
サイドメニュー → **物品対応**（物品部のみ閲覧可能）

対象案件: **物品破損報告（出展団体から）のみ**

**対応の流れ:**

1. 案件一覧から案件を選ぶ
2. 内容を確認する（写真が添付されている場合あり）
3. **ステータスをボタンで変更する**
   - 未対応 → 対応中 → 対応済み
4. **返信を入力して送信する**

> 常に最新情報が自動で反映されます（Realtime監視）。

## スライド 21｜通知について

### Push通知が届くタイミング

| 通知 | 受け取る人 |
|---|---|
| 新規連絡案件が来た | 本部 / 会計 / 物品（種別による） |
| 巡回タスクが割り当てられた | 割り当てられた巡回担当 |
| 返信・ステータス更新 | 案件を出した出展団体 |

### 通知を受け取るために
ブラウザの通知許可が必要です。
各画面上部の **「通知を有効にする」バナー** から設定してください。

## スライド 22｜よくある操作ミスと注意点

| よくあるミス | 正しい操作 |
|---|---|
| 巡回タスクを「向かいます」なしで完了しようとする | 必ず先に「向かいます」を押す |
| 質問タブで写真を送ろうとする | Discordで連絡する |
| 対応中のメンバーに巡回を割り当てようとする | 別のメンバーを選ぶ（赤く表示されている） |
| 通知が来ない | Push通知バナーから許可設定を確認する |

## スライド 23｜まとめ

**このシステムで変わること**

- 電話・口頭・LINE での連絡が → **アプリの連絡案件** に集約
- 「誰が対応したか分からない」が → **ステータス・担当者・返信履歴** で全て見える
- 鍵の管理が → **貸出/返却/施錠確認タスクの自動生成** でつながる
- 巡回の指示が → **タスクとして担当者のスマホに届く**

> 当日は各自のロールの画面だけを使います。
> 分からないことは本部サポートの担当者へ。
